프레임 정합 루프

프레임 하나가 채널에서 나와 TrackedFrame으로 IntegrationThread에 넘어가기까지. 거부된 프레임도 버려지지 않는다 — 이전 포즈를 유지한 채 융합 게이트로 내려간다.

실패 분류 — ETrackFailure

  • NoModel 맵이 아직 없음 — 초기 프레임에서 정상
  • NoLocalTarget 그 위치에 맵이 거의 없음
  • TooFewInliers 대응점 절대 하한 미달
  • LowOverlap 개수는 찼지만 프레임 대비 비율 낮음
  • ImplausibleMotion prior에서 물리적으로 불가능한 이동 — fitness가 좋아도 오수렴 (maxStepMeters)

등속 prior — 두 조건이 다 차야 켜진다

  • 연속 2회 채택 (1-프레임 간격 delta 보장) AND 직전 step > 2 cm
  • 저속(~5 mm/frame)에서 delta 재적용은 포즈 노이즈 재적용 — 주기-2/3 진동 실측 (477 중 229 거부)
  • 조건 미달이면 직전-포즈 prior — capture/에서 476/476 추적
  • 근거: docs/ICP_REGISTRATION_QUALITY.md §9.6

융합 게이트의 비대칭

  • inlier/overlap 실패는 융합하면 틀린 포즈로 맵이 오염 — 다음 프레임의 정합 타깃이 망가짐
  • NoModel·NoLocalTarget은 오염시킬 맵이 없음 — 거부하면 부트스트랩 불가
  • 건너뛴 수는 PipelineStats::skippedFusions로 관측

§2 · Process · Global Registration 2025+

FPFH 파이프라인은 무엇으로 대체되는가

현재 global 트래커는 FPFH + RANSAC 계열이다. 2025년 이후 지형은 세 노선 — 고전 파이프라인의 각 단계를 무엇이 갈아끼우는지를 단계별로 겹쳐 보면 아래와 같다. 결정적 전환점은 RANSAC의 자리: 호환성 그래프 프루닝 + GNC non-minimal 솔버가 차지했다.

기법 핵심 아이디어 FPFH 파이프라인에서 대체하는 것 실시간 적합성 · 비고
KISS-MatcherICRA 2025 · MIT-SPARK Faster-PFH(FPFH 재구현, 단일스레드 ~4.5×) + k-core 그래프 프루닝 + GNC 솔버를 한 C++ 라이브러리로 통합. 모든 파라미터가 복셀 크기의 배수. FPFH → Faster-PFH, RANSAC → k-core + GNC ~14 Hz, 200K+점에서 TEASER++ 대비 20×. C++/MIT, Python 바인딩, ROS2 예제. 실시간 재위치추정 1순위.
TurboRegICCV 2025 maximal clique(지수) 대신 3-clique + Pivot-Guided Search(선형)로 가설 생성. RANSAC만 교체 — 특징은 그대로 3DMAC 대비 208× + recall 상승. CPU/GPU. 최소 침습 경로.
FastMACCVPR 2024 대응 그래프에 그래프 신호처리 — 고주파 보존 스펙트럼 샘플링으로 그래프 축소. RANSAC만 교체 MAC 대비 최대 80× (KITTI), 실시간 도달.
MAC++3DV 2025 투표 기반 seed로 clique pool 유도 + 점진적 가설 평가. RANSAC만 교체 극저 inlier 비율(원조 MAC 실패 구간)에서 SOTA. 오프라인 품질 상한용.
HeMoRaCVPR 2025 대응 샘플링 확률을 비지도 강화학습(Maximal Reward Propagation)으로 학습. RANSAC의 샘플링 분포 비지도가 지도학습 SOTA(VBReg)를 상회.
BUFFER-XICCV 2025 Highlight 복셀/반경 자동 추정 + 학습 검출기 제거(FPS 회귀) + 패치 좌표 정규화로 재학습 없는 zero-shot 일반화. Lite판은 연산 43% 절감. FPFH + RANSAC 전체 1개 데이터셋 학습 → 12개 무튜닝 평가. GPU 추론 필요 — 실시간에는 차선.
ZeroMatchCVPR 2025 Stable Diffusion 특징 + FPFH를 결합한 기술자로 학습 없이 zero-shot RGB-D 매칭. FPFH를 보강 (시맨틱 보완재로 재등장) RGB-D 특화. FPFH가 완전히 죽지 않은 사례.
DINOReg2025 (arXiv) DINOv2 시각 특징 + 기하 특징을 패치 레벨 융합, mixed positional embedding. 학습 기술자 (GeoTransformer 계보) RGB-D 정합에서 GeoTransformer 대비 대폭 향상 주장.
C-GenRegCVPR 2026 포인트 클라우드를 World Foundation Model로 멀티뷰 RGB 렌더 → VFM 대응 + 기하 브랜치 융합. 완전 training-free. FPFH + RANSAC 전체 실내 SOTA, 실외에서 학습 기법 능가 주장. 오프라인.
G3RegIEEE T-ASE 2024 점 특징 대신 평면/클러스터/선 프리미티브(Gaussian Ellipsoid) + 피라미드 호환성 그래프 + GNC 검증. 점 단위 특징 자체를 세그먼트로 LiDAR 특화 (distrust-and-verify).

본 저장소 권고 서열

  • ① KISS-Matcher — 복셀-배수 파라미터화가 이 코드베이스의 "voxel에 맞춘 maxCorrDist" 규약과 같은 철학. C++/MIT, 학습 모델 의존 없음
  • ② TurboReg / FastMAC — 기존 FPFH 위에 estimator만 교체하는 최소 침습 경로
  • ③ BUFFER-X-Lite — GPU 여유가 있고 도메인 변동이 클 때
  • MAC++ · C-GenReg · FUSER는 오프라인 품질 상한용

세 노선의 분화

  • 고속 수제 특징 + 그래프 프루닝 + GNC — 로보틱스/SLAM 실무의 사실상 기본값이 되는 중
  • robust estimator 단독 진화 — RANSAC만 갈아끼움, 선형 복잡도로 실시간 진입
  • zero-shot 학습 기술자 — 2023–24 "벤치마크 내 SOTA" 경쟁이 "무튜닝 크로스 도메인" 경쟁으로 전환

그 외 관찰

  • 2D 파운데이션 모델(DINOv2, SD, WFM) 특징의 3D 유입이 지배적 패턴
  • 학습된 키포인트 검출기는 일반화 약점으로 지목 — FPS로 회귀 (BUFFER-X)
  • FUSER(CVPR 2026): 쌍별 정합 없이 멀티뷰 feed-forward 전역 포즈 — 다음 세대 신호
  • correspondence-free 계열(EquivAlign 등)은 아직 물체 스케일 중심

요컨대 "FPFH가 죽었다"기보다 "RANSAC이 죽었다" — 특징은 더 빠른 재구현(Faster-PFH)이나 시맨틱 보완(ZeroMatch)으로 살아남았고, 가설 샘플링의 자리는 호환성 그래프 + GNC가 차지했다.
